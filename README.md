# Paranza Barrese L'Infinita — Demo V5

Bozza dimostrativa non ufficiale, non approvata e non rappresentativa di un sito già pubblicato dalla Paranza.

## Contenuto
- Sito statico responsive per desktop, iPhone e Android.
- Popup iniziale con Infinity che digita il messaggio di presentazione.
- Assistente Infinity con risposte dimostrative locali.
- Chat Membri dimostrativa.
- Sezione invito a conoscere la Paranza; non raccoglie adesioni.
- Tutte le immagini e gli stili sono incorporati in `index.html`.

## Pubblicazione su GitHub
1. Crea un repository GitHub, ad esempio `paranza-infinita-demo`.
2. Carica `index.html` nella cartella principale del repository.
3. Per GitHub Pages: **Settings → Pages → Deploy from a branch → main → /(root)**.
4. Salva e attendi che GitHub mostri l'indirizzo pubblico.

## Pubblicazione su Cloudflare Pages
1. Apri Cloudflare Dashboard → **Workers & Pages → Create → Pages**.
2. Collega il repository GitHub `paranza-infinita-demo`.
3. Framework preset: **None**.
4. Build command: lasciare vuoto.
5. Build output directory: `/`.
6. Avvia il deployment.

## Note tecniche
- Nessuna build, framework o dipendenza esterna.
- Nessun database o backend.
- Chat e Infinity sono simulazioni locali.
- Il pulsante di interesse non raccoglie dati e non invia richieste.
- La pagina deve rimanere chiaramente identificata come **PROGETTO DIMOSTRATIVO — NON UFFICIALE**.
